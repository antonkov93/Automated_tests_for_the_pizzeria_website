### Для запуска проекта локально нужно:

1. Создать новый проект в IDE (например в PyCharm);
2. Открыть консоль Bash и ввести команду для клонирования: git clone https://github.com/antonkov93/Automated_tests_for_the_pizzeria_website.git
3. Перейти в папку склонированного проекта командой: cd Automated_tests_for_the_pizzeria_website
4. Установить зависимости из файла "requirements.txt" командой: pip install -r requirements.txt
5. Запустить все тесты командой: python -m pytest
